# 模式选择器按钮不显示 - 诊断报告

## 🔍 问题描述

用户报告："没有看到按钮"（监听模式选择器按钮）

## 🎯 根本原因

模式选择器按钮有**两个显示条件**，必须**同时满足**才会显示：

```vue
<div class="mode-selector-wrapper" v-if="useWebsocket && chatStore.isConnected">
```

### 条件 1: `useWebsocket === true`
- **位置**: `FloatingChatInterface.vue:16`
- **默认值**: `true`
- **状态**: ✅ 默认满足

### 条件 2: `chatStore.isConnected === true`
- **位置**: 来自 Pinia store
- **要求**: WebSocket 必须成功连接
- **状态**: ❓ 需要用户手动连接

## ✅ 解决方案

### 步骤 1: 点击"连接"按钮

1. 打开应用 `http://localhost:5174/`
2. 在聊天界面的**右上角**找到连接状态按钮
3. 如果显示 "⚪ 未连接" 或 "🔴 连接失败"，点击该按钮
4. 等待状态变为 "🟢 已连接"

### 步骤 2: 验证按钮显示

连接成功后，您应该能在**输入框上方**看到：

```
🤖 auto
```

这就是监听模式选择器按钮！

│  💬         🟢 已连接         │  ← 头部

### 层级结构
- 位于 `.simple-input-area` 内
- 在 `.simple-input-wrapper` (输入框和按钮) **上方**
- `margin-bottom: 8px` 与输入框分隔

## 🔧 如果连接按钮不工作

### 检查服务器配置

检查 `.env.local` 文件：

```bash
# 查看当前配置
cat .env.local | grep VITE_WS_URL
```

应该显示类似：
```
VITE_WS_URL=ws://111.230.57.211:8888
```

### 检查服务器是否运行

确保 WebSocket 服务器正在运行：
- 地址: `ws://111.230.57.211:8888`
- 协议: WebSocket
- 状态: 正常接受连接

### 浏览器控制台检查

打开浏览器开发者工具 (F12)，查看控制台：

**正常连接应该看到**:
```
✅ WebSocket连接成功
🟢 已连接
```

**连接失败会看到**:
```
❌ WebSocket连接失败: ...
🔴 连接失败
连接失败: Error: ...
```

## 🎨 按钮样式说明

### 默认样式
- **背景**: 半透明白色 `rgba(255, 255, 255, 0.1)`
- **边框**: 圆角 `20px`
- **内容**: 图标 + 文字 (例: `🤖 auto`)
- **位置**: 输入框上方，左对齐

### 悬停效果
- 背景变亮
- 轻微上移 `transform: translateY(-1px)`
- 鼠标变为手型

### 点击后下拉菜单
- 向上弹出 (位于按钮上方)
- 黑色半透明背景 `rgba(0, 0, 0, 0.9)`
- 显示三个选项:
  - 🤖 auto - 自动停止
  - 👆 manual - 手动停止
  - 📡 realtime - 持续监听

## 📊 诊断检查清单

- [ ] **WebSocket 服务器正在运行**
  - 检查服务器地址和端口
  - 确认服务器接受连接

- [ ] **点击了"连接"按钮**
  - 查看右上角状态
  - 等待 "🟢 已连接" 状态

- [ ] **浏览器控制台无错误**
  - 打开 F12 开发者工具
  - 查看 Console 标签

- [ ] **在正确位置查找**
  - 输入框**上方**
  - 不是在输入框里面
  - 不是在消息区域

## 💡 常见误解

### ❌ 错误预期
- "按钮应该一直显示"
- "按钮在输入框里面"
- "按钮在消息区域"

### ✅ 正确理解
- **必须先连接 WebSocket**
- 按钮在输入框**上方**独立区域
- 只在 WebSocket 模式下显示

## 🎯 快速验证步骤

1. 打开 `http://localhost:5174/`
2. 右上角点击 "⚪ 未连接" 按钮
3. 等待变为 "🟢 已连接"
4. 向下看输入框上方
5. 应该看到 `🤖 auto` 按钮

**如果完成以上步骤后仍未看到按钮，请提供浏览器控制台的错误信息！**
